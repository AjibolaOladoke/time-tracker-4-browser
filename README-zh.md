\[ 简体中文 | [English](./README.md) \]

网费很贵是一款用于上网时间统计的浏览器插件，使用 rspack，TypeScript 和 Element-plus 进行开发。你可以在 Firefox，Chrome 和 Edge 中安装并使用它。

-   统计用户在不同网站上的浏览时间，和访问次数
-   统计用户阅读本地文件的时间
-   网站白名单，过滤不需要统计的网站
-   支持多个域名合并统计，用户可以自定义合并规则
-   统计用户在不同时段的上网习惯
-   限制每天浏览指定网站的时间
-   支持数据导出导入
-   支持将数据备份到 Gist，以及远程查询已备份的多端数据
-   支持夜间模式
